Installation
------------

Install with ::

    pip install git+https://github.com/exp4-age/metro-eval@main

If you want cythonized `metro2hdf` and `sort_events`, cython
and numpy need to be installed first, e.g. ::

    pip install cython numpy

and a C++ compiler needs to be available.
